# 阿豆的注音課・第 1 課（ㄅ　ㄆ　ㄇ）

給閔以森（小名阿豆）的互動注音課，約 20 分鐘。用電腦或平板打開網址即可上課，不必安裝軟體。

## 怎麼用

1. 用 **Chrome** 或 **Edge** 打開課程網頁（這兩個瀏覽器比較容易有「中文（台灣）」語音）。
2. 爸爸陪在旁邊，一起按「準備好了，開始！」。
3. 每個步驟都可以按 **🔊 再聽一次**。如果電腦發音不準，請爸爸跟著念給阿豆聽，沒關係。
4. 上完課後，下載「第 1 課作業單」，列印出來用鉛筆慢慢描寫。網頁負責聽、認、玩；寫字還是用紙本比較好。

課程網頁：https://myc0426-dot.github.io/zhuyin-adou/

作業單：同一網址下的 [lesson01_作業.pdf](lesson01_作業.pdf)

右上角可以打開「顯示計時」，幫爸爸看 20 分鐘。

## 這一課有什麼

1. 暖身專注遊戲：聽了再動、1-2-3 木頭人
2. 認識 ㄅ ㄆ ㄇ（點圖卡聽聲音）
3. 動一動休息（跳三下、轉一圈）
4. 聽音辨識小遊戲（6 題）
5. 教育部標準筆順動畫，並可在螢幕上描寫（ㄅ 是 1 畫，ㄆ、ㄇ 是 2 畫）
6. 複習、鼓勵，並預告下一課 ㄈ ㄉ ㄊ

筆順依據教育部《國語注音符號手冊》，符號外形取自全字庫正楷體（TW-Kai）。
