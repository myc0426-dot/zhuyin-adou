# 阿豆的注音課・第 1 課（ㄅ　ㄆ　ㄇ）

給閔以森（小名阿豆）的互動注音課，約 20 分鐘。用電腦或平板打開網址即可上課，不必安裝軟體。

## 怎麼用

1. 用瀏覽器打開課程網頁（電腦或平板都可以）。
2. 爸爸陪在旁邊，一起按「準備好了，開始！」。
3. 每個步驟都可以按 **🔊 再聽一次**。聲音是預先錄好的台灣中文（HsiaoChen）。如果單獨的注音還有一點點不準，請爸爸跟著念給阿豆聽，沒關係。
4. 上完課後，下載「第 1 課作業單」，列印出來用鉛筆慢慢描寫。網頁負責聽、認、玩；寫字還是用紙本比較好。

## 這一課有什麼

1. 暖身專注遊戲：聽了再動、1-2-3 木頭人
2. 認識 ㄅ ㄆ ㄇ（點圖卡聽聲音）
3. 動一動休息（跳三下、轉一圈）
4. 聽音辨識小遊戲（6 題）
5. 教育部標準筆順動畫，並可在螢幕上描寫（ㄅ 是 1 畫，ㄆ、ㄇ 是 2 畫）
6. 複習、鼓勵，並預告下一課 ㄈ ㄉ ㄊ

畫面裡的阿豆，是用小朋友的卡通形象當課程吉祥物。筆順依據教育部《國語注音符號手冊》，符號外形取自全字庫正楷體（TW-Kai）。

## 語音

所有句子與單獨的 ㄅ ㄆ ㄇ 都預先用 `zh-TW-HsiaoChenNeural` 錄成 `audio/` 裡的 MP3。單獨的音是直接念注音符號本身，不用「玻、坡、摸」替代。若某個音檔載入失敗，網頁會退回瀏覽器內建語音。

之後若要加課或改台詞，請編輯並執行 `audio/generate.py`，再執行 `pack.py` 重新打包 `index.html`。
